# Match the following Question Generator 

## Introduction 
One of the main problem educators face is to generate new questions for practice. Specifically questions of the type Assertion & Reason and Match the following. 

I thought why not generate the questions programmatically, so I tried to create a "Match the following" question generator to Practice for NEET, JEE or any other examination. 

## Usage
The program generates HTML file for the Match the following type questions. The data will be given in form of CSV. The data file attached is the data for all the dimensions of all physical quantities.
